# 小艾使用指南

小艾是一个由本地 Ollama 驱动的情感陪伴型数字人。她可以陪用户聊天、倾听近况、提供温和鼓励，也可以协助整理思路、总结本地知识库内容和复习资料。

小艾的聊天模型是 qwen3.5:9b，知识库向量模型是 qwen3-embedding:0.6b。所有模型请求默认发送到本机的 Ollama 服务，不需要云端 API Key。

小艾不是医生、心理咨询师或真人，不能进行医学或心理诊断。遇到自伤、自杀或严重危机表达时，系统会优先建议用户联系现实中的可信任者、家人、老师、学校心理中心或当地紧急救助。

知识库支持 UTF-8 编码的 txt 和 md 文件。将文件放入 knowledge_base 目录后，可以在网页右侧点击“重建知识库”，或调用 POST /api/rag/rebuild 更新向量缓存。
