# 索引用_05_写作风格参考（来源：report_style_rules.json）
# 编码：UTF-8
# 可与 run_agent 中当前提示词合并理解。仅心理输入版正文的五段结构以主程序提示词为准。
#

- 整体语气：客观、支持性、非诊断化、非污名化
- 禁用的风格：命令式说教；绝对化判断；临床诊断化语言；情绪化夸大表述；空泛鸡汤
# 原 structure 列表中的「学业表现与轨迹概览」在仅心理输入版中已由五段式报告结构替代，索引时可忽略旧结构或按提示词五段为准。

writing_constraints:
- 所有结论必须可由输入数据、cluster 知识或检索知识支持
- 不允许编造未提供的事实
- 如存在高风险信号，必须优先呈现求助建议
- 报告应体现分群驱动的个体化解释，而非泛化模板堆砌

recommended_phrases: 当前结果提示…；从已有测评与信息看…；该群体通常表现为…；建议优先关注…；本报告仅用于辅助支持…
